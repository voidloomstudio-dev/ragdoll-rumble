# Ragdoll Rumble

Funny multiplayer ragdoll physics shooter built with **Godot 4.7**.

## Quick Start
1. Install [Godot 4.7+](https://godotengine.org/download)
2. Open `game/project.godot`
3. Press F5

## Features
- Ragdoll physics combat
- 12 outfits, 7 abilities, coin shop
- Character customize with 3D preview
- 4 maps (Arena, Forest, Farm, House) with Blender props
- Host/Join multiplayer (2–4)
- Mobile virtual joysticks
- Canva UI mockups + Kenney CC0 SFX

## Controls
| Action | PC | Mobile |
|--------|-----|--------|
| Move | WASD | Left stick |
| Look | Mouse | Right stick |
| Shoot | LMB / F | FIRE |
| Ability | Q | — |
| Reset ragdolls | R | — |
| Cycle map | M | — |
| BR mode | B | — |
| Menu | ESC | — |
